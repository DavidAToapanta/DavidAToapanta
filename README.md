## ⭐ Proyecto destacado: HERO GYM

Plataforma web para la gestión operativa de gimnasios, desarrollada para
administrar clientes, membresías, pagos, asistencias, productos y estadísticas.

- Frontend desarrollado con **Angular y TypeScript**.
- Backend construido con **NestJS, Prisma y PostgreSQL**.
- Autenticación y control de acceso mediante roles.
- Despliegue con **Firebase, Google Cloud Run y Cloud SQL**.
- Integración biométrica con **ZKTeco MA300 y ZKBio CVAccess**.
- Sincronización de eventos mediante un bridge local en Node.js.

[![Frontend](https://img.shields.io/badge/Ver_Frontend-HERO_GYM-DD0031?style=for-the-badge&logo=angular)](https://github.com/DavidAToapanta/Hero-gym)
